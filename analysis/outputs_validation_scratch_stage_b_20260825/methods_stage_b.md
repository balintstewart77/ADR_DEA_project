# Scratch-coder Stage B methods

Frozen inputs were POST-028 REDCap export, POST-009 baseline, POST-011 hard case, POST-019 crosswalk, PRO-018, RED-036, RED-013, MOD-001 rc2 taxonomy and MOD-006 Fable 5 production output. Stage B calls Stage A's audited parsing, validation-included filtering, joins and canonical unordered `frozenset` representation, with restored restricted paths supplied only at load time. The baseline population is 150 records; the 75 hard cases are explicitly diagnostic, disagreement-enriched and non-representative. There were no structurally invalid responses, so structural-validity sensitivity is identical; the one exposure-flagged baseline project remains primary.

For every label independently, human support is positive iff at least two of A/B/C assign it. This labelwise reference is analytical, not adjudicated gold standard, and Purpose majority labels are not capped. Baseline support defines RARE (<10), LOW SUPPORT (10–29), and STANDARD (>=30). Rare Domain/Purpose labels retain contingency/prevalence counts only; kappa, precision, recall and F1 are withheld. Macro metrics are unweighted means over the fixed baseline-observed support>=10 Domain/Purpose label set. A macro replicate is conservatively undefined if any fixed eligible label metric is undefined, avoiding a changing label set.

Exact agreement is equality of the complete unordered set. Jaccard is intersection/union, with empty/empty=1. Binary orientation is reference=majority human and prediction=Fable: TP=both positive, FP=model-only, FN=human-only, TN=both negative. Precision=TP/(TP+FP), recall=TP/(TP+FN), F1=2PR/(P+R). Cohen kappa uses the conventional binary observed and marginal expected agreement. Tag raw agreement=(TP+TN)/N; positive agreement=2TP/(2TP+FP+FN); negative agreement=2TN/(2TN+FP+FN). Binary two-rater Gwet AC1 uses Po, p=(p_A+p_B)/2, Pe=2p(1-p), AC1=(Po-Pe)/(1-Pe).

Bootstrap resampling uses 2,000 record-level samples, seed 20260714, keeping linked A/B/C/L values together and preserving duplicate draws. Related metrics use shared deterministic draws. Percentile intervals are 2.5/97.5 Hyndman–Fan Type 7 (linear). Undefined replicate values are excluded only for that statistic; an interval is `CI NOT ESTIMABLE` below ceil(0.90*attempts)=1800 valid replicates. No source IDs, titles, record-level values, FP/FN lists, disagreement cases, or adjudication population are output. Rare-label examples and adjudicated issue notes are deferred until adjudication to preserve masking.
